# Green Hero – Pixelart-Bilddaten

Die dokumentierten Einzelbilder sind **exakt 265 × 265 Pixel** groß.

Die dargestellten Figuren sind **exakt 245 Pixel hoch**, mit jeweils 10 Pixel
transparentem Rand oben und unten. Die Blickrichtungen bleiben erhalten. Alle
Bilder verwenden dieselbe **24-Farben-Palette plus Transparenz**.

| Datei                                | Bildgröße       |
| ------------------------------------ | --------------- |
| Gehpose nach rechts SW               | 265 × 265 Pixel |
| Gehpose nach links SO                | 265 × 265 Pixel |
| Gehpose nach rechts Diagonale SO     | 265 × 265 Pixel |
| Gehpose nach links Diagonale SW      | 265 × 265 Pixel |
| Spritesheet mit beiden Ausrichtungen | 530 × 530 Pixel |

Das Spritesheet besteht aus **zwei Feldern à 265 × 265 Pixel ohne
Zwischenraum**. Die Einzelbilder wurden direkt daraus ausgeschnitten.
