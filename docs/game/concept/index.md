Dieser Bereich sammelt unverbindliche Vorschläge, Alternativen und offene
Ausarbeitungen. Dazu gehören auch Vorschläge von Assistenten.

Ein Konzept ist weder Kanon noch geltendes Gamedesign. Nach einer Annahme wird
das Ergebnis in den passenden verbindlichen Bereich eingearbeitet. Ändert es
eine bereits angenommene Festlegung, wird die Begründung zusätzlich unter
[Entscheidungen](../decisions/index.md) dokumentiert.
