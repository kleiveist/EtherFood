# English documentation status

Detailed English game-concept translations are not available yet. The
[German game concept](../de/index.md) is authoritative, and its overall status
is still `in-progress`.

A detailed translation may begin only when both gates are satisfied:

1. the complete German game concept has reached `complete`; and
2. the individual German source document has reached `approved`.

Until then, the public [README](../../README.md) is the English project
overview. Technical implementation documentation remains available in the
[developer area](../developer/index.md). No mirrored English concept chapter
structure is created before the translation gate opens.
